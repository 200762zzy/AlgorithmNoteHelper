# AlgorithmNoteHelper v0.1.1

修复一个会把记录「藏起来」的缺陷。**数据从未丢失**，但界面上会让人以为丢了。

## 修了什么

**症状：** 保存一条错题后点「完成复习」，这条记录就从列表里消失了；把状态下拉切到
未复习 / 待复习 / 已掌握，哪个筛选都找不到它，只有「全部状态」还看得到。

**原因：** 「待复习」这个词在两个地方被当成了两个意思。详情页里它表示**状态**
（这条记录还在复习轮次里），而筛选下拉里被实现成了**队列**（今天到期、该复习的）。
复习完成后算法把下次复习排到了明天，于是这条记录变成"状态是待复习、但不在待复习筛选里"，
在**每一个**筛选口径下都找不到。数据一直好好的，只是被列表藏起来了。

**修复：**

- 「待复习」恢复为**状态**口径：只要还在复习轮次里，就一定能通过它找到
- 新增独立的「今天该复习」口径（队列）；原来的快捷按钮也改名为「今天该复习 (N)」
- 列表第二行开始显示排期：`待复习 · 今天` 或 `待复习 · 10-14`，
  这样"它为什么不在今天的队列里"一眼就能看出来
- 完成复习后状态栏会明确提示：该条已移出「今天该复习」队列，但状态仍是「待复习」

新增 4 项回归测试（含界面层断言），全套 121 项通过。

## 下载后怎么用

1. 下载下面的 `AlgorithmNoteHelper-v0.1.1-win64.zip`，解压到任意目录。
   建议**不要**放在 `C:\Program Files\` 这类只读位置。
2. 双击 `AlgorithmNoteHelper.exe`。
3. **首次运行 SmartScreen 会拦一下** —— 点「更多信息」→「仍要运行」。
   这不是病毒警报（程序没有代码签名，SmartScreen 不做病毒扫描），详见压缩包内的 `FIRST_RUN.md`。
4. 数据存在 exe 旁边的 `data/`。整个文件夹拷到 U 盘或另一台电脑，错题一起跟过去。

> ⚠️ **不要用 Typora / Obsidian 直接编辑 `data/notes/*.md`。** 程序保存时会整篇重新生成。

**从 v0.1.0 升级：** 解压覆盖即可，`data/` 目录不会被动到。

## 这个版本有什么

- **只填标题就能录**：题目简述是唯一必填字段，难度与错因有默认值、可事后补
- **剪贴板快速新建**（`Ctrl+Shift+N`）：标题取自剪贴板首行，是链接就顺手填进题目链接
- **三档复习评分**（忘记 / 困难 / 轻松）驱动 SM-2，自动生成「今天该复习」队列
- **「已掌握」不是终点**：间隔到 30 天以上进入已掌握，但逾期一周仍会回到队列
- 按关键词 / 标签 / 难度 / 状态筛选；列表显示每条的下次复习日期
- 导出单条错题为 Markdown（front-matter 齐全，可直接进 Typora / Obsidian）
- **单文件全量快照**：一个 JSON 含索引与全部正文，可备份、可恢复、
  **可与同学互导题解**（重复条目可选跳过 / 覆盖 / 收为副本）

## 数据安全

原子写、每次保存前轮转备份、删除前先存快照、单实例锁（防双开互相覆盖索引）、
数据目录不可写时自动回落 `%APPDATA%`、导入前校验 id 并自动备份现场。

## 已验证 / 未验证

**已验证：** 121 项 pytest 全绿；分发件通过两项非交互自检（数据层自检 + Qt 平台插件
与界面层自检）。

**未验证：** 只在作者的 Windows 11 25H2 家用版上跑过，**没有在其他机器 / 其他 Windows
版本上测试过**；UI 无自动化测试，交互与手感靠手工验证。

## 已知限制

- 没有 C++ 语法高亮（列入 V0.2）；搜索只覆盖索引字段，不含正文全文搜索
- 快速新建是**应用内**快捷键，不是系统级全局热键
- 不支持把外部编辑过的 md 回读进应用
- 打包体积 119.6 MB（PySide6 onedir 的固有开销，压缩后约 47 MB）
- 未做代码签名，所以每次分发都会触发 SmartScreen 提醒

## 不想用 exe？

装好 Python 3.10+ 之后：`pip install -r requirements.txt` 然后 `python main.py`。
