# AlgorithmNoteHelper v0.1.2

两个来自真实使用的改进：**看得见整个复习循环**，以及**代码终于看得全**。

## 新增：复习计划

点工具栏的「**复习计划**」，把复习循环整个画出来：

- 上方是**未来 14 天的到期分布柱状图**：最左一根是逾期，今天用强调色，一眼看出复习压力落在哪天；
- 下方按到期日**分组列出**具体是哪几道，双击一条可以直接跳到主窗口里那一条（会自动复位筛选，
  免得目标被关键词或状态筛选挡住）；
- 已掌握的条目也在其中 —— 它们不是终点，只是间隔被拉长了。这里展示的是"复习循环本身"，
  而不是"此刻该做什么"，后者由「今天该复习」回答。

## 改进：代码看得全了

上一版为了治布局失衡，把所有文本框设成了定高 140px —— 结果一段 40 行的 AC 代码只能看到约 7 行。
现在：

- **代码框最小 200px，且纵向可伸展**：窗口越大，代码框越高（多余空间全给代码，不再留白）；
- **不折行**：长行用横向滚动条看，比折行更好读；
- 每个代码框右上角有「**放大**」按钮，打开接近全屏的等宽编辑器，改完直接写回；
- 散文框（错误思路 / 错因详述 / 正确思路 / 复盘总结）放宽到 80px。

## 同时修掉的缺陷

- **记录被"藏起来"**：复习完的条目状态仍是「待复习」，但筛选下拉里的「待复习」当时是"今天到期的队列"
  语义，于是它在每一个筛选口径下都找不到（只有「全部状态」可见）。**数据从未丢失。**
  现在「待复习」是状态口径，另有独立的「今天该复习」队列口径；列表第二行也直接显示
  `待复习 · 今天` / `待复习 · 10-14`。
- **界面自检会留垃圾目录**：`--self-check-gui` 早先用 `mkdtemp` 造样例数据，而系统临时目录不可写时
  `tempfile` 会静默回退到当前工作目录。现在改为只读打开真实数据目录，不写数据、不建临时目录。

新增 9 项测试，全套 **130 项通过**。

## 下载后怎么用

1. 下载 `AlgorithmNoteHelper-v0.1.2-win64.zip`，解压到任意目录（建议**不要**放在 `C:\Program Files\`）。
2. 双击 `AlgorithmNoteHelper.exe`。
3. **首次运行 SmartScreen 会拦一下** —— 点「更多信息」→「仍要运行」。
   这不是病毒警报（程序没有代码签名，SmartScreen 不做病毒扫描），详见压缩包内的 `FIRST_RUN.md`。
4. 数据存在 exe 旁边的 `data/`。整个文件夹拷到 U 盘或另一台电脑，错题一起跟过去。

> ⚠️ **不要用 Typora / Obsidian 直接编辑 `data/notes/*.md`。** 程序保存时会整篇重新生成。

**从旧版本升级：** 解压覆盖即可，`data/` 目录不会被动到。

## 已验证 / 未验证

**已验证：** 130 项 pytest 全绿；分发件通过两项非交互自检（数据层 + Qt 平台插件与界面层）。

**未验证：** 只在作者的 Windows 11 25H2 家用版上跑过，**没有在其他机器 / 其他 Windows 版本上测试过**；
UI 无自动化测试，交互与手感靠手工验证。

## 已知限制

- 没有 C++ 语法高亮（列入 V0.2）；搜索只覆盖索引字段，不含正文全文搜索
- 快速新建是**应用内**快捷键，不是系统级全局热键
- 不支持把外部编辑过的 md 回读进应用
- 打包体积 119.6 MB（PySide6 onedir 的固有开销，压缩后约 47 MB）
- 未做代码签名，所以每次分发都会触发 SmartScreen 提醒
