# AlgorithmNoteHelper v0.1.3

两个变化：**代码有了语法高亮**，以及**多了一种不会触发 SmartScreen 的分发形式**。

## 新增：C++ 语法高亮

代码框现在给关键字 / 类型与标准库名 / 函数名 / 数字 / 字符串 / 注释 / 预处理指令七类着色，
配色刻意低饱和（界面本身仍是单色）。表单里的两个代码框与「放大」窗口共用同一套高亮。

两条实现说明：分词是**不依赖 Qt 的纯函数**，所以能直接单测（10 项测试不需要图形环境）；
逐字符扫描而不是堆正则，为的是正确处理字符串里的 `//`（`"https://x"` 不是注释）
与跨行的 `/* ... */`。

## 新增：便携版（不触发 SmartScreen）

以前只有一个未签名的 exe，Windows SmartScreen 会提示「已保护你的电脑」。而且按微软文档，
**未签名文件每个新版本都要从零累积信誉** —— 不是"点一次就好"，是每发一版都要再点一次。

买证书解决不了：EV 证书 2024 年起已不再即时豁免，OV 证书也要攒信誉。所以改用另一个办法：
**让 Python 官方（Python Software Foundation）已签名的 `pythonw.exe` 来运行程序**，
被执行的程序本身就是受信任的。

本机实测三组对照（Windows 11 25H2）：

| 组 | 被双击的文件 | 签名 | 网络标记 | 结果 |
| :-- | :-- | :-- | :-- | :-- |
| A | 极小的未签名 exe | 无 | 无 | **有**蓝色提示 |
| B | `run.bat` → 全新副本的 `pythonw.exe` | Python Software Foundation | 无 | **无**提示 |
| C | 同 B，所有文件带网络标记（等同从下载的 zip 解压） | Python Software Foundation | 有 | **无**提示 |

C 组是关键：它对**从网上下载的同学**同样有效。

### 这一版发布两个包，功能完全相同

| 压缩包 | 体积 | 双击 | SmartScreen |
| :-- | :-- | :-- | :-- |
| `AlgorithmNoteHelper-v0.1.3-win64.zip` | 约 47 MB | `AlgorithmNoteHelper.exe` | 每个新版本提示一次 |
| `AlgorithmNoteHelper-v0.1.3-portable-win64.zip` | 约 50 MB | **`run.bat`** | **不提示** |

想要没提示就用 portable 那个。两条路都保留是因为便携版还比较新：它依赖 `.bat` 启动器，
而 `.bat` 在少数受管控的机器上可能被执行策略禁掉 —— 那时退回 exe 版即可。

两种形式的启动方式、SmartScreen 行为、数据位置都写在压缩包里的 `FIRST_RUN.md`。

## 下载后怎么用

1. 解压到任意目录（建议**不要**放在 `C:\Program Files\` 这类只读位置）。
2. 按上表双击对应的入口。
3. 数据存在程序文件夹里的 `data/`。整个文件夹拷到 U 盘或另一台电脑，错题一起跟过去。

> ⚠️ **不要用 Typora / Obsidian 直接编辑 `data/notes/*.md`。** 程序保存时会整篇重新生成。
> 要外部编辑，请用「导出 md」。

**从旧版本升级：** 解压覆盖即可，`data/` 目录不会被动到。

## 这个版本有什么

- **只填标题就能录**：题目简述是唯一必填字段，难度与错因有默认值、可事后补
- **剪贴板快速新建**（`Ctrl+Shift+N`）
- **三档复习评分**（忘记 / 困难 / 轻松）驱动 SM-2，自动生成「今天该复习」队列
- **复习计划**：未来两周的到期分布柱状图 + 按到期日分组的清单，双击直接跳过去
- **「已掌握」不是终点**：间隔到 30 天以上进入已掌握，但逾期一周仍会回到队列
- **代码区**：带 C++ 语法高亮、可随窗口伸展、不折行，另有「放大」按钮
- 按关键词 / 标签 / 难度 / 状态筛选；列表显示每条的下次复习日期
- 导出单条错题为 Markdown；**单文件全量快照**可备份、可恢复、可与同学互导题解

## 数据安全

原子写、每次保存前轮转备份、删除前先存快照、单实例锁（防双开互相覆盖）、
数据目录不可写时自动回落 `%APPDATA%`、导入前校验 id 并自动备份现场。

## 已验证 / 未验证

**已验证：** 144 项 pytest 全绿；两种分发形式都通过两项非交互自检（数据层 + Qt 平台插件与
界面层），并核对了 `runtime\pythonw.exe` 的签名有效性。

**未验证（如实说明）：**

- 只在作者的 Windows 11 25H2 家用版上跑过，**没有在其他机器 / 其他 Windows 版本上测试过**；
- SmartScreen 的实测是在**作者本机**完成的，不同 Windows 版本 / 安全软件配置下结论可能不同；
- 便携版的 `.bat` 启动器**没有在受管控（禁用脚本执行）的机器上验证过**；
- UI 无自动化测试，交互与手感靠手工验证。

## 已知限制

- 搜索只覆盖索引字段，不含正文全文搜索；快速新建是应用内快捷键，不是系统级全局热键
- 不支持把外部编辑过的 md 回读进应用
- 打包体积：exe 版 118 MB、便携版 139 MB（压缩后约 47 / 50 MB）
- exe 版未做代码签名，每个新版本都会提示一次 SmartScreen
